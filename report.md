# Customer Service Agent Report

## Project Title
Offline Flask Customer Service Agent

## Objective
To build an offline AI-powered customer service chatbot that answers customer queries using predefined intents.

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Scikit-learn

## Features
- Customer Chat Interface
- 25+ Intents
- Offline Support
- SQLite Database
- Chat History
- Analytics Dashboard
- Responsive UI

## Folder Structure
- app.py
- chatbot.py
- database.py
- train.py
- intents.json
- templates/
- static/

## Conclusion
This project demonstrates an offline customer support chatbot developed using Flask and SQLite for handling customer queries efficiently.
